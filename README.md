# Серая застава

Самостоятельный PvPvE extraction-хоррор в Roblox. В локальном прототипе можно выбрать охотника, экипироваться и отправиться на Кедровый перегон, чтобы вернуться со свидетельством и наградой.

## Локальный запуск

Требуются Python 3.10+, Roblox Studio и инструменты из `rokit.toml`. Установите Rokit из [официального релиза](https://github.com/rojo-rbx/rokit/releases), затем выполните `rokit install` и `./scripts/build.sh` из папки проекта. Если Rokit спросит о доверии, сверяйте владельцев инструментов с `rokit.toml`.

Откройте `build/GreyOutpost-Lobby.rbxl` в Studio и запустите **Play**. Нажмите **Начать экспедицию** или **Быстрый контракт**. WASD — движение, ЛКМ — выстрел, R — перезарядка, E — взаимодействие, Q — резонанс, F — аптечка, M — карта, T — поднять товарища рядом. Два дополнительных файла запускают самостоятельные матчевые места в Studio. Скрипт сборки заново создаёт сцену и интерфейс из `scripts/generate_lobby.py`. Изменения из Studio переносите в исходники перед следующей сборкой.

Полная локальная проверка запускается командой `./scripts/check.sh`.
