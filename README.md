# Hunt: Showdown 1896 in Roblox

Исходный проект Roblox Experience. Сейчас создана файловая основа Rojo; игровые системы и сцена ещё не реализованы.

## Структура

- `src/shared` — общие модули.
- `src/server` — серверная логика и проверки.
- `src/client` — клиентское управление и интерфейс.
- `default.project.json` — отображение файлов в Roblox Studio.
- `docs/tooling.md` — исследование инструментов и принятые решения.

Перед синхронизацией Rojo проверьте открытый place в Studio: он может содержать существующую работу, которой пока нет в этой папке. Источник истины необходимо подтвердить до первой синхронизации.
