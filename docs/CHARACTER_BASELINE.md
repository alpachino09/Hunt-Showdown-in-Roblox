# Исходное состояние персонажей

| Подсистема | Текущее состояние | Точка интеграции |
|---|---|---|
| Выбор и сохранение | `Catalog.luau` содержит `reed`, `vale` и `shaw`. `LobbyFlow` проверяет выбор на сервере, `Profiles` сохраняет идентификатор | Сохранить идентификаторы. Добавить четвёртый после проверки его модели и учесть старые профили |
| Витрина | `Workspace/Station/DisplayHunter` собирается из авторской геометрии. `HunterIdle` двигает верх тела, голову и хват. Выбор меняет только цвет пальто | Сохранять композицию и настройку движения. Для нового охотника тестировать отдельный предпросмотр |
| Игровой персонаж | `Raid.start` загружает аватар вызовом `Player:LoadCharacterAsync`, ставит его на нужный спавн и оставляет контроль состояния за сервером | Подключать вид проверенного персонажа в одной точке спавна. Покрыть вход, смерть и возврат |
| Первое лицо | `Field.client.luau` управляет FOV, штатной камерой Humanoid и смещением при приседании | Оставить игровые привязки. Руки и точки хвата сначала отработать в отдельном стенде |
| Сборка | Rojo собирает лобби, экспедицию и ночную смену. `Station` создаётся генераторами Python, ассеты перечислены в `ASSET_LIBRARY.md` | Модели, риги и испытательный стенд собирать из файлов. Изменения на текущей вкладке Studio не заменяют источники |

Проверена локальная вкладка Studio `GreyOutpost-Cinematic-Final.rbxl`. В ней есть авторская витрина, GUI, оба шаблона карты в ServerStorage и стандартный стек скриптов проекта. Studio успешно создала тестовый R15 по пустому HumanoidDescription, его использовали для сверки размеров, узлов и названий креплений, затем удалили временную модель.

Первый рабочий персонаж — Элиас Рид, ветеран перегона. Для проверки используется отдельный стенд. До приёмки модели и базовых движений исходная сцена лобби и три игровые сборки доступны в штатном виде. Базовая точка нового этапа — коммит `742c60a` и [PR лобби](https://github.com/alpachino09/Hunt-Showdown-in-Roblox/pull/3).
