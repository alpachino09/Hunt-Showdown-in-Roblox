# Инструменты проекта «Серая застава»

В `rokit.toml` закреплены Rojo 7.7.1, StyLua 2.6.0, Selene 0.32.0, Luau LSP 1.70.1 и Lune 0.11.1. Подключение Studio MCP ранее проверено на локальном лобби. Текущий интерфейс состоит из стандартных Roblox GUI Instances. Сторонних игровых пакетных зависимостей пока нет.

## Выбор для проекта

- **Roblox Studio Agent Plugin / Studio MCP**: используется для проверки локального места в Studio.
- **Roblox Creator Docs и Luau**: основные справочники API и языка.
- **Rojo + Rokit + StyLua + Selene + Luau LSP**: используются для сборки и проверки. Перед синхронизацией сверять соответствие исходников месту Studio.
- **Wally**: подключать при первой реальной внешней зависимости; закрепить версии и проверить исходники пакетов. Пока пакетных зависимостей нет.
- **EL4CTEO/roblox-skills**: актуальные инструкции; локальные навыки Roblox уже доступны агенту. Не копировать весь набор в проект без конкретной потребности.
- **ProfileStore**: кандидат для сохранения охотников, денег и инвентаря после проектирования схемы, миграций и тестов в Studio. Последний push старше года: повторно проверить актуальность перед интеграцией.
- **RbxUtil**: выбирать отдельные модули по потребности, а не добавлять весь набор заранее.
- **Fusion**: предварительный выбор для HUD, лобби и инвентаря; финально после проверки существующего UI. React Luau параллельно не подключать.
- **Нативные RemoteEvent/RemoteFunction**: начальная сеть с серверной проверкой оружия, урона, денег и инвентаря. Blink только если профилирование покажет сетевую проблему.
- **Нативные зоны через части/CollectionService**: базовый вариант; ZonePlus рассмотреть лишь при сложных зонах и после проверки сопровождения.
- **FastCast2**: исследовательский кандидат для баллистики, без установки до сравнения с собственным raycast, тестов пробития и проверки лицензии.
