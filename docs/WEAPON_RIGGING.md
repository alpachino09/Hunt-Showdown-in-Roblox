# Риг «Фонаря»

`scripts/generate_weapon_lab.py` собирает авторскую учебную модель `ReplicatedStorage.Lantern` для места WeaponLab. Пять именованных групп с собственными прозрачными `Origin`: `Body`, `Barrel`, `Extractor`, `LiveRound` и `SpentCase`. Модель создаётся Rojo из локального генератора и использует встроенные дерево и металл Roblox.

| Группа | Опорные точки |
| --- | --- |
| Body | `RightGrip` для основной кисти, `Brace` для временной опоры второй кисти и `Sight` для FPP |
| Barrel | `LeftGrip` на цевье, `Chamber` для визуальных предметов и `Muzzle` для вспышки |
| Extractor, LiveRound, SpentCase | Собственные pivots для смещения, переноса и падения |

Обе кисти используют `ArmIK`, вынесенный из существующего стенда охотников. Он вычисляет положение плеча, локтя и кисти по R15 и учитывает локальную точку на ладони. Локоть гнётся в заданную плоскость с устойчивым запасным направлением при совпадении осей.

Контроль (готовая поза, Studio Solo): все четыре охотника прошли порог 0,03 stud. Численный тест измеряет совпадение опорных маркеров; проверка силуэта отдельно обнаружила пересечение приклада с корпусом и привела к изменению длины и поворота. Независимое сгибание пальцев и проверка пересечений на всех фазах ещё предстоят. [Результаты](WEAPON_TEST_RESULTS.md)
