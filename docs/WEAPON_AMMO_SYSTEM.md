# Боезапас и состояние заряда

`src/shared/weapons/WeaponDefinitions.luau` хранит определения. Catalog продолжает экспортировать два игровых оружия с прежними ID и значениями. «Фонарь» определён для разработки стенда.

`src/server/weapons/WeaponStateService.luau` создаёт состояние на участника. Raid применяет существующую частоту запросов, условия матча и проверку направления; после подтверждённого расхода выполняет исходный raycast. Для двух игровых оружий заряд пополняется одной серверной транзакцией по завершении прежней задержки. Таймер связан с экземпляром фазы, персонажем и участником. Нокдаун и выход из матча прекращают отложенную перезарядку.

Для одной игровой ячейки фазы `Open`, `Eject`, `Insert` и `Close` последовательно обновляют состояние. При опоздании обработчика сервер применяет все истёкшие фазы. Пустая ячейка пропускает `Eject`. При завершении `Insert` резерв уменьшается на 1, ячейка получает `Live`. Отмена сохраняет выполненные переходы и завершает цикл через `Close`. Выстрел разрешён только после закрытия. Старые ревизии не меняют новое действие.

`lune run tests/unit/WeaponState.luau` покрывает оба текущих оружия, перезарядку с резервом, отсрочку, повторную обработку, сброс, сухое состояние и отмену по обе стороны вставки. Сквозной тест состояния «Фонаря» следует провести на стенде с фактическим сервером Studio.
