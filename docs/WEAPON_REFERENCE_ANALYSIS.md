# Художественные ориентиры этапа 04

Первичный обзор от 24.11.2026. Crytek при выпуске Hunt: Showdown 1896 описала выбор между центральной и опущенной точками прицеливания. Для «Серой заставы» это повод измерить центральную линию прицела на разных форматах окна и сравнить кадрирование удержания и ADS на своём R15. [Официальная публикация о выпуске](https://www.huntshowdown.com/news/introducing-hunt-showdown-1896-out-now-on-pc-ps5-xbox-series-x-s)

[Руководство Crytek](https://www.huntshowdown.com/manual) и [официальная подборка видео](https://www.huntshowdown.com/media/videos) собраны как источники для следующего прохода. Разбор покадровых примеров ещё предстоит. Игровые цифры, тайминги, размеры и хореография для проекта пока не выбраны.

Первый образец «Серой заставы» должен ясно показывать готовое, открытое и пустое состояния с двух ракурсов. На следующем проходе нужны собственная силуэтная схема, сравнение положения кистей и таблица визуальных фаз. Серверный переход и отображение каждого предмета предусмотреть до создания клипов. Последовательность остальных четырёх семейств указана в [передаче](../AI_HANDOFF.md).
