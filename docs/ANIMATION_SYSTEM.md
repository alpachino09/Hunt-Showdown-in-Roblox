# Анимации охотников

## Первый набор

Исходный `Quaternius-Standard-source.glb` расположен в `assets/animations/Locomotion`. Он извлечён из бесплатного Standard-архива Quaternius, лицензия CC0 1.0. [Архив автора](https://opengameart.org/content/universal-animation-library)

`scripts/retarget_veteran_motion.py` сэмплирует девять движений в Blender. Исходные направления бёдер и рук переводятся в систему координат Roblox и сопоставляются с исходными направлениями суставов Элиаса. Генератор выносит перенос по вертикали в Root. Горизонтальное движение остаётся в Humanoid. Для воспроизведения в локальной сборке используются проверенные численные позы, полученные из исходных клипов. Импортированные Animation ID для них не нужны.

`src/shared/characters/Locomotion.luau` интерполирует позы по времени, смешивает переходы за 0,17 с и сохраняет фазу шага при переключении скорости. Частота цикла следует за измеренной горизонтальной скоростью. Переход к прыжку, воздуху и приземлению следует за состоянием Humanoid. Полы пальто получают небольшое движение через два собственных сустава. Клиент стенда настраивает только локальную демонстрацию и показывает активный клип.

Ключи стенда в Studio Play. WASD — движение, J — бег, Shift — спринт, C — приседание, пробел — прыжок, V — первое или третье лицо. Управление и анимации работают в отдельном `GreyOutpost-HunterLab.rbxl`.
