# Бесплатные ресурсы для охотников

| Задача | Источник и оценка | Решение |
|---|---|---|
| Пропорции и крепления тела | Roblox Classic / HipToBeSquare, 9/10 как ориентир | Использовать для размеров и проверки структуры в Studio. Видимые части спроектировать под собственную анатомию и одежду. [Референс Roblox](https://create.roblox.com/docs/avatar/character-bodies/project-files) |
| Готовое базовое тело | Universal Base Characters, CC0, 7/10 | Качественные универсальные деформации. Скульпт современный, с другими пропорциями. Выбран собственный R15-силуэт. [Пакет Quaternius](https://quaternius.com/packs/universalbasecharacters.html) |
| Основные движения | Universal Animation Library Standard, CC0, 9/10 | Скачан архив автора от 2025 года. Подтверждены `Idle_Loop`, `Walk_Loop`, `Jog_Fwd_Loop`, `Sprint_Loop`, `Crouch_Idle_Loop`, `Crouch_Fwd_Loop`, `Jump_Start`, `Jump_Loop`, `Jump_Land`. Исходный риг отличается от R15. [Архив и лицензия](https://opengameart.org/content/universal-animation-library) |
| Альтернативные движения | Mixamo, 8/10 | Годится для ретаргета в игре. Для воспроизводимой сборки выбран открытый CC0-источник. [FAQ Adobe](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) |
| Пальто, жилет, брюки | Витрина «Серой заставы» и Fabric012, CC0 для материала, 8/10 | Переиспользовать визуальный язык, контуры деталей и адаптированные карты ткани. Посадка на новую геометрию будет проверена на сгибах. [ambientCG](https://ambientcg.com/view?id=Fabric012) |
| Потёртая кожа перчаток, ремня и сапог | Fabric Leather 01, Rob Tuytel, CC0, 8/10 | 1K карты цвета, нормали и шероховатости. Частоту швов и зерна подстроить по масштабу детали. [Poly Haven](https://polyhaven.com/a/fabric_leather_01) |
| Шляпа | Leather Cowboy Hat, enkvadrat, CC BY-SA 4.0, 8/10 | Подходящие форма и PBR. На первом персонаже выбран уже имеющийся авторский силуэт с уширенными полями. [Модель enkvadrat](https://opengameart.org/content/leather-cowboy-hat) |
| Сапоги, кобура, пояс, сумка | MakeHuman System Assets и открытые наборы одежды, 6/10 | Подходящие материалы изучены. Для узнаваемых тяжёлых сапог и крепления на бедре потребуется отдельная геометрия. [MakeHuman Community](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html) |
| Винтовочный реквизит | Авторская наружная модель из этапа лобби, 8/10 для пропорций | Компоновку сохранить для стенда. Модель крепится к кисти, поза второй руки настраивается отдельно. [Библиотека проекта](../ASSET_LIBRARY.md) |

SHA-256 загруженного архива `universal_animation_librarystandard.zip` — `18ff1a7215f4852b320203e8aaf02a1578b5c8eef9027fbaedfcedc7b85a3ac2`. Лицензия CC0 входит в архив. Ретаргетированные клипы будут регистрироваться по мере их проверки в игре.
