# Интерактивные объекты карты

## Текущий статус

Генератор создаёт невидимые неколлизионные markers с исходными координатами и вариантами моделей. Это конфигурация для будущих систем, не рабочие двери, стёкла или подъёмники.

| Тип | Количество исходных точек | Текущий результат |
|---|---:|---|
| Doors | 339 | Markers, варианты моделей |
| Windows | 193 | Markers, варианты ставен/стекла |
| Ladders | 105 | Markers, исходная длина в detail |
| Elevators | 19 | Markers |
| Crank gates | 18 | Markers |
| Cage gates | 11 | Markers |
| Breakable fences | 32 | Markers |
| Stairs | Отдельный `stairs` список | Endpoints и ширина |

Данные находятся в `assets/mammons-gulch/reference/points.json`. Исполняемый код сторонних моделей не используется.

## Целевая архитектура

- Общий конфигурационный модуль для каждого типа: door, window/shutter/glass, ladder, elevator, gate, destructible.
- CollectionService tags для обнаружения объектов, Attributes для параметров и server-side состояния. Не создавать отдельный большой Script для каждой двери.
- Server подтверждает расстояние, прямую видимость, состояние и конфликтующие запросы. Клиент получает анимацию/звук, но не определяет результат.
- Коллизии создаются отдельно от визуальных мешей. Дверные петли и проёмы должны совпадать; никаких декоративных лестниц.
- Elevator требует серверной платформы, ограничителей, passenger policy, звука и синхронизации, а не tween из LocalScript.
- Разрушение ограничивается заранее подготовленными состояниями для стекла, баррикад, хрупких ящиков и отдельных дверей.

## Порядок

Сначала La Plata Mine: измеренные двери, ставни, лестницы и один подъёмник с Solo Play, затем два клиента для конфликтов и синхронизации. Только после эталона система распространяется на остальные комплексы. До этого момента текущий этап не считается интерактивно завершённым.
