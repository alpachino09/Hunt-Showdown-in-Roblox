# WeaponLab — камеры и таймлайн

Открыть `build/GreyOutpost-WeaponLab.rbxl` после `./scripts/build.sh`. Управление: ЛКМ — выстрел, ПКМ — прицел, R — цикл перезарядки, X — отмена, V — камера, 1–4 — выбор охотника. В стенде используется отдельный RemoteEvent `WeaponLabInput`; Expedition сохраняет действующий Combat.

Сервер записывает единый снапшот `LanternState` на текущем Character. Клиент наблюдает его только при изменении и вычисляет позу от серверных timestamps. `WorldmodelController` применяет движение механизма и IK к модели для каждого наблюдаемого охотника. В FPP `Viewmodel` переносит видимые детали и руки в систему координат камеры вместе, сохраняя относительные точки хвата. Для ADS опорой служит Attachment `Sight`; при переключении в TPP камера отодвигается, локальная FPP-копия снимается.

Процедурный цикл включает открытие, перемещение экстрактора и гильзы, взятие реквизита, вставку и закрытие. При отмене в фазе Open закрытие начинается с достигнутой доли поворота. Один циклически используемый визуальный экземпляр гильзы скрывается по окончании короткого падения. Момент расхода резерва подтверждает сервер.

У стенда пока нет чистовой геометрии, индивидуальных пальцев, звука, финальной покадровой приёмки и теста с двумя клиентами. Опубликованных AnimationId нет, движение задаётся кодом. [Серверное состояние](WEAPON_AMMO_SYSTEM.md) · [Проверки](WEAPON_TEST_RESULTS.md)
