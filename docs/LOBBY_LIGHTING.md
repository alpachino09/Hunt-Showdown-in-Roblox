# Свет у лесного поста

Глобальный пресет лобби хранится в `default.project.json`. В Roblox Studio используется Realistic с мягкими тенями. Плотная облачность убирает ярко-синий просвет в заднем плане. Время 16.55 оставляет достаточно отражённого света для ткани и грунта. Мягкая холодная подсветка слева от камеры дополняет янтарный контровой свет фонаря у ограды. Второй слабый фонарь отмечает груз.

| Настройка | Значение |
|---|---:|
| Brightness / ExposureCompensation | 1.75 / −0.31 |
| EnvironmentDiffuseScale / EnvironmentSpecularScale | 0.35 / 0.45 |
| ShadowSoftness | 0.4 |
| Atmosphere Density / Haze / Offset | 0.37 / 2.8 / 0.08 |
| ColorCorrection Saturation / Contrast | −0.40 / 0.065 |
| Bloom Intensity / Threshold | 0.13 / 1.48 |
| Clouds Cover / Density | 0.96 / 0.65 |

Локальная экспедиция убирает элементы атмосферного пресета и восстанавливает их по возвращении. Отдельно собранные места экспедиции и ночной смены используют собственные свойства Lighting.
