# Работа над «Серой заставой»

- Перед изменениями проверь Git, выполни безопасный fetch и прочитай PROJECT_PLAN.md, DEVELOPMENT_PROGRESS.md, NEXT_STEPS.md.
- Соблюдай порядок этапов из PROJECT_PLAN.md. Используй существующие файлы и компоненты.
- Источник файловой сборки — этот репозиторий. Перед синхронизацией с местом Studio проверь содержимое места и владельца каждого подраздела.
- После каждого законченного изменения прогони подходящие проверки, обнови документы, создай отдельный коммит и отправь его в рабочую ветку GitHub. Проверь SHA удалённой ветки. При завершении этапа создай PR в main. Не используй принудительный push в main.
- Секреты, личные данные и ассеты без права распространения держи вне репозитория. Для используемых ассетов фиксируй происхождение в ASSET_LIBRARY.md.
- При работе с Luau, Studio, UI и 3D применяй релевантные навыки. Выбор инструментов и условия подключения зависимостей описаны в docs/tooling.md.
- Сервер подтверждает результаты, награды, экономику и другие значимые изменения. Отчёт отличает проверку кода от фактически пройденного теста Studio.
