# План разработки «Серой заставы»

Текущая цель — локально запускаемая застава и структура отдельных мест. Следующая контрольная точка — полноценный маршрут одного матча.

| Шаги | Порядок реализации |
|---|---|
| 1–6 | Инвентаризация → референсы → дизайн → архитектура → отдельные Places → рабочее лобби |
| 7–11 | Охотник → экипировка → команды → подбор → перенос |
| 12–17 | Карта → контроллер → FPP → первое оружие → попадания и урон → здоровье и нокдаун |
| 18–25 | Обычный противник → босс → улики → «Резонанс» → опечатывание → свидетельство → эвакуация → полный цикл матча |
| 26–30 | Сохранение → экономика → расширение оружия → дополнительные монстры → дополнительные боссы |
| 31–36 | Детали карты → погода → звук → интерфейс → прогрессия → второй режим |
| 37–40 | Оптимизация → многоклиентные тесты → исправления → подготовка к запуску |

Контрольный сценарий шага 25 проходит от лобби через контракт и эвакуацию до возвращения. В первой полноценной версии дополнительно проверяются сохранение, прогрессия, повторный матч и взаимодействие нескольких команд. Детали правил и границы среза описаны в GAME_DESIGN.md.
