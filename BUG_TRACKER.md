# Ошибки и ограничения

- Матчевые места подготовлены локально. Для облачных тестов нужно зарегистрировать три места в одном приватном Experience.
- Набор, инвентарь, отряды, прогресс и снабжение пока показывают состояние прототипа. Соответствующие игровые системы ещё не подключены.
- Витринный охотник использует временную процедурную модель. Звук лобби отсутствует.
